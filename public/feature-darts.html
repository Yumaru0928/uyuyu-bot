ダーツ チェックアウト

残りスコアから、上がり目のルートを調べます

ダーツの残りスコアを入力すると、3本以内で上がれる「チェックアウト(上がり目)」のルートを教えてくれます。

コマンドの使い方

/calculate-darts-checkout type:ファットブル out:ダブルアウト score:100
オプション必須内容
type必須ファットブル / セパレートブル
out必須マスターアウト / ダブルアウト / オープンアウト
score必須残りスコア(1〜180)

ルールの選び方

ブルの種類(type)

  • ファットブル: ブルの外側も内側も、どちらも50点になります。
  • セパレートブル: 外側が25点、内側が50点です。

アウトのルール(out)

ルール最後の1本
ダブルアウトダブル(ブルの内側を含む)で上がる
マスターアウトダブル・トリプル・ブルのどれかで上がる
オープンアウトどこに入っても上がれる

結果の見方

  • 推奨ルート(第1候補): 投げる順に並べたルートです。「T20 ➔ D20」なら、トリプル20のあとにダブル20を投げて上がります。必要な本数も表示します。
  • その他のアレンジ候補: 別の上がり方があるときに、最大3通りまで表示します。1本多く投げるルートも入ることがあります。
  • 3本以内で上がれない点数のときは、「3投以内でチェックアウト不可能です」と表示します。

表記

表記意味
S1〜S20シングル
D1〜D20ダブル
T1〜T20トリプル
D-BULLブルの50点(内側)
BULLアウターブル25点(セパレートブルのときだけ)

結果の例

条件残り推奨ルートその他の候補
ファットブル / ダブルアウト100T20 ➔ D20D-BULL ➔ D-BULL / T20 ➔ S20 ➔ D10
ファットブル / ダブルアウト32D16S16 ➔ D8 / S12 ➔ D10
ファットブル / ダブルアウト170T20 ➔ T20 ➔ D-BULLなし(これだけ)

ご利用にあたって

  • ルートは、少ない本数と、よく使われる上がり目(D20、D16、D8など)を優先して選んだものです。ご自身の得意な上がり目に合わせて、候補から選んでください。
  • 入力できるスコアは、1〜180です。
