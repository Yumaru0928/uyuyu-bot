絵文字リアクション

言葉に反応して、うゆゆ絵文字を付けます

「うゆゆ」などの言葉が書き込まれたメッセージに、Botがうゆゆ絵文字でリアクションします。コマンドは必要なく、招待するだけで動きます。

反応する言葉

メッセージの中に、次のどれかが含まれていると反応します。

パターン反応する言葉の例
うゆゆ(ひらがな・カタカナの組み合わせ)うゆゆ / ウユユ / うユゆ
uyuyu(uやyが続いてもOK)uyuyu / uuyyuu / UYUYU
myuが3回myumyumyu
suyarun(最後のnは何個でも)suyarun / suyarunnnn
  • 大文字と小文字は区別しません(UYUYU でも反応します)。
  • 全角の英数字(ｕｙｕｙｕ)や、半角カタカナ(ｳﾕﾕ)も、同じ言葉として扱います。
  • メッセージの一部に含まれていれば反応します。「うゆゆしい」のように、言葉の途中でも反応します。
  • Botが書いたメッセージと、DM(ダイレクトメッセージ)には反応しません。

反応する例・しない例

メッセージ反応
今日もうゆゆ反応する
ｕｙｕｙｕ(全角)反応する
うゆゆしい反応する(言葉の一部)
うゆ / uyu / myumyu反応しない(足りない)
Botのメッセージ、DM反応しない

使われる絵文字

1つのメッセージに、絵文字を1つだけ付けます。うゆゆ絵文字16種類と rolling_uyuyu の、合計17種類から、毎回ランダムに選びます。一覧は うゆゆ絵文字の一覧 にあります。

絵文字をサーバーに登録する必要はありません。ただし、Botがそのチャンネルで「リアクションの追加」と「外部絵文字の使用」ができる権限を持っている必要があります。

チャンネルごとにオフにする

静かにしたいチャンネルでは、自動リアクションを止められます。方法は2つです。

  1. コマンドで切り替える: 止めたいチャンネルで /disable-auto-react-channel を実行します。再びオンにするときは、同じチャンネルで /enable-auto-react-channel を実行します。結果は、実行した本人にだけ表示されます。
  2. ダッシュボードで切り替える: ダッシュボードの「Auto-React」で、チャンネルごとのスイッチをオン/オフします。まとめて切り替えるときに便利です。

どちらも「チャンネルの管理」権限を持つ人だけが使えます。設定はサーバーごとに保存されます。

初期状態では、すべてのチャンネルで自動リアクションがオンです。

うまく動かないとき

  • そのチャンネルがオフになっていないか、ダッシュボードで確認してください。
  • Botがそのチャンネルを見られて、リアクションを付けられる権限があるか確認してください。権限が足りないときは、何も表示されずに反応しません。
  • メッセージがすぐに消された場合も、リアクションは付きません。
